# Lease Math

Florida-style move-in and rent-to-income calculator.

Use it to test a 1-bed against a biweekly check before you sign.

## Live

After GitHub Pages is on: https://alex-caro.github.io/lease-math/

## What it computes

- Monthly net from a biweekly check
- Rent as a percent of take-home
- Move-in cash (first month + deposit + fees)
- Leftover after rent, food, car, phone
- Pass / tight / fail against a 30% rent rule and a 50% leftover rule

No listings. No brokerage. Numbers only.
